# Automations

This folder stores automation exports, snapshots, notes, and proposed YAML.

Home Assistant/MCP is the preferred source of truth for normal automations.

Do not assume files here are live-loaded by Home Assistant unless explicitly documented.

Use this folder for:

- exported automation YAML
- proposed automation drafts
- change records
- rollback references
- feature notes

Exports should go under:

```text
exports/
```

New automations should normally be created through MCP after approval, then exported or documented here.
