# Helpers

This folder stores helper exports, snapshots, notes, and proposed helper definitions.

Home Assistant/MCP is the preferred source of truth for helpers.

Do not assume files here are live-loaded by Home Assistant unless explicitly documented.

Use this folder for:

- helper inventories
- helper design notes
- exported helper YAML/config
- change records
- rollback references

Exports should go under:

```text
exports/
```

New helpers should normally be created through MCP after approval, then exported or documented here.
