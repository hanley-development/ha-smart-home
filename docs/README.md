# Documentation

This folder contains Home Assistant organization and planning notes.

Useful docs:

- `areas.md` — current Home Assistant areas
- `labels.md` — current Home Assistant labels
- `known-issues.md` — cleanup items and known problems
- `entity-naming.md` — naming conventions
- `dashboard-style.md` — dashboard design guidance
- `automation-patterns.md` — automation patterns
- `mcp-safety.md` — MCP safety rules

Dashboard source files are not stored here. Dashboards are UI-managed and should be inspected or changed through Home Assistant UI or MCP-supported tools.
