# Dashboard Layouts

## Home view

Purpose: Show the most important whole-home status at a glance.

Recommended sections:

1. Critical alerts
2. Security summary
3. Garage summary
4. Climate summary
5. Lighting summary
6. Network/maintenance summary

## Security view

Purpose: Show safety and access status.

Recommended sections:

1. Alarm state
2. Exterior doors
3. Locks
4. Motion
5. Cameras
6. Recent activity

## Garage view

Purpose: Show garage status and common controls.

Recommended sections:

1. Garage door state
2. Entry door/contact sensors
3. Garage lights
4. Motion/occupancy
5. Temperature/freezer sensors
6. Alerts/timers

## Climate view

Purpose: Show comfort and HVAC status.

Recommended sections:

1. Current indoor temperature
2. Thermostat controls
3. Humidity
4. HVAC mode
5. Temperature trends
6. Alerts

Purpose: Group lights by area.

## Network view

Purpose: Show home infrastructure status.

## Maintenance view

Purpose: Show things that need attention.
