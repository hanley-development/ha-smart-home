# Helper Selection Guide

## input_boolean

Use for true/false modes: guest mode, vacation mode, quiet hours, notification toggles.

## input_number

Use for thresholds or configurable values: alert delays, temperature thresholds, humidity thresholds.

## input_select

Use when there are several named modes: house mode, security mode, lighting scene mode.

## input_datetime

Use for user-configurable times: quiet hours start/end, sprinkler start time.

## timer

Use for delayed or repeated workflows: garage door left open, motion clear delay, laundry repeat delay.

## counter

Use for counting repeated events: alert count, motion trigger count, failed update count.

## Prefer helpers when

Use helpers when a value should be configurable from the UI or reused by multiple automations.
