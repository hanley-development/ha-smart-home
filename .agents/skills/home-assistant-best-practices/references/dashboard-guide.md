# Dashboard Guide

## Dashboard policy

Dashboards are managed through the Home Assistant UI.

Do not create YAML dashboards, edit YAML dashboards, edit `.storage`, or convert UI dashboards to YAML.

## Design principles

Dashboards should be mobile-first, clean, fast to understand, grouped by area or purpose, and safe to operate.

## Recommended structure

1. Home overview
2. Security
3. Garage
4. Climate
5. Lights
6. Cameras
7. Network
8. Maintenance

## Useful overview content

Home overview should show alarm/security state, open exterior doors, active motion, climate summary, important alerts, unavailable critical devices, and low battery count.
