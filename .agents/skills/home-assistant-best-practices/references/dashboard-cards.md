# Dashboard Cards Reference

## Important

This project uses UI-managed dashboards.

Do not create or edit YAML dashboard files unless explicitly asked.

Card examples may be used as snippets for manual UI use.

## Recommended card types

Use clear, functional cards:

- Entities card
- Tile card
- Mushroom cards, if installed
- Button card, if installed
- Conditional card
- Gauge card
- History graph
- Markdown card
- Alarm panel card
- Thermostat card
- Picture glance for cameras

## Security section

Useful entities: alarm state, exterior doors, locks, motion sensors, cameras, nighttime mode, guest mode.

## Garage section

Useful entities: garage door cover, garage entry contact, garage motion, garage lights, garage temperature, freezer/fridge temperature, door-left-open timer/status.

## Network section

Useful entities: internet status, UniFi gateway status, important server pings, UPS state, NAS status.

## Maintenance section

Useful entities: low battery devices, unavailable devices, ESPHome updates, Zigbee health, failed automations.
